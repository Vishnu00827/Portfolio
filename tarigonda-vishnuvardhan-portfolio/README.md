# Tarigonda Vishnuvardhan — Portfolio

A responsive static portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and links
- `style.css` — responsive styling
- `script.js` — navigation and reveal effects
- `resume.pdf` — supplied resume
- `assets/profile.png` — profile photo

## Important: set the real GitHub profile
In `index.html`, replace every occurrence of:

`https://github.com/your-github-username`

with Tarigonda Vishnuvardhan's actual GitHub profile URL.

## Run locally
Open the folder in VS Code and use the Live Server extension, or open `index.html` in a browser.

## Deploy
Upload the complete folder to a GitHub repository and enable GitHub Pages from the repository's Settings → Pages.
